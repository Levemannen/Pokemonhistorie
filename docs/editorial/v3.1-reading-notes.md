# Redaksjonell egenkontroll

| Perspektiv | Funn |
|---|---|
| Dramaturgi | Gjennomlest S19 → S23 → S24. Retur og forberedelser ligger før måleren slår inn i siste felt. |
| Valg | Sammenlignet responsene for de to Mira-valgene og kontrollert at spilleren får se konsekvensen før neste side. |
| Karakter | Lumi reagerer forskjellig på brevet og fotoet, Shinx kan vurdere den faktiske varmeplanen, og Miras advarsel endres med barnets tillit. |
| Pokémon | Starterens reaksjon i S16 og S24 velges fra virkelig starter. S25 prioriterer reisende Pikachu/Hoothoot før lokale varianter. |
| Bokmål | Vedleggets bokmål er beholdt. Den nye trereplikken forklarer formen på fordypningen; noe informasjon gjentas i de bevarte trinnvise hintene. |
| Engelsk | Samme graf og valg-ID som bokmål. Forfatterens engelske formuleringer og navn er bevart. |
| Kontinuitet | I grunnmanuset viste trappen til bildet uten utstyrsvilkår; kun betingelsesmarkører ble lagt rundt de to eksisterende setningene. Ingen ny replikk. |
| Barneleser | En egen returknapp på hver valgliste reduserer letingen. S25 og enkelte avslutninger er lange. Tempo, ordforståelse og opplevd valgfrihet må vurderes med barn. |
| Bilde | Detaljfunn per scene ligger i bildeoversikten. S23 og S24 bør skille tydeligere mellom venting og den aktive åpningen. |
| Teknikk | Gjennomgått import, gamle kvitteringer, lagring, bonusvilkår, historikk og frakoblet lesing. Ingen ekstern tjeneste er lagt til. |
